# البيت — لعبة هروب رعب (نسخة أندرويد)

مشروع أندرويد بسيط بيشغّل `asylum_game.html` جوه WebView بملء الشاشة، وGitHub بيبني منه ملف APK أوتوماتيك.

## الطريقة (من غير Android Studio)

1. اعمل Repository جديد على GitHub.
2. ارفع **كل محتويات** الفولدر ده (Add file ← Upload files، واسحب الملفات والفولدرات).
   - فولدر `.github` لازم يترفع (هو اللي فيه ملف البناء). لو مظهرش عندك، اعمل ملف جديد من Add file ← Create new file واكتب في الاسم `.github/workflows/build-apk.yml` وانسخ محتوى الملف.
3. افتح تاب **Actions** ← **Build Android APK** ← **Run workflow** (وبعد كده بيشتغل لوحده مع كل رفع).
4. لما يخلص (حوالي 5–10 دقايق)، افتح التشغيل الأخير ونزّل **asylum-game-apk** من تحت (Artifacts) — جواه `asylum-game.apk`.
5. انقل الـ APK للموبايل وثبّته (لازم تسمح بالتثبيت من مصدر غير معروف).

**لو عايز رابط تحميل دايم:** اعمل Release بتاج يبدأ بـ `v` (مثلاً `v1.0`)، والـ APK هيتحط تلقائي في صفحة Releases.

## الأونلاين (السيرفر)

اللعبة بتتصل بـ WebSocket، وGitHub مش بيشغّل سيرفرات، فالسيرفر (`server/server.js`) لازم يشتغل في مكان تاني:

- **على نفس الواي فاي:** على الكمبيوتر شغّل `cd server && npm i && node server.js`، وفي اللعبة اكتب `ws://عنوان-الكمبيوتر:8080` (مثلاً `ws://192.168.1.5:8080`).
- **على الإنترنت:** ارفع فولدر `server` على استضافة Node مجانية زي Render وخد منها رابط، واكتبه في اللعبة بالشكل `wss://اسمك.onrender.com`. (الخطة المجانية بتنام لما محدش يستخدمها، فأول اتصال ممكن ياخد دقيقة.)
- **عشان العنوان يتكتب لوحده:** حط الرابط في `gradle.properties` عند `GAME_SERVER_URL` قبل البناء. اللعبة بتفتكر العنوان اللي بتكتبه بعد أول دخول.

اللعب الفردي مش محتاج سيرفر.

## تخصيصات سريعة

| عايز تغيّر | روح فين |
|---|---|
| اسم التطبيق | `app/src/main/res/values/strings.xml` (`app_name`) |
| اتجاه الشاشة (أفقي/طولي) | `AndroidManifest.xml` ← `screenOrientation` (`sensorLandscape` أو `sensorPortrait`) |
| الأيقونة | `app/src/main/res/drawable/ic_launcher_foreground.xml` |
| رقم الإصدار | `app/build.gradle` ← `versionCode` و`versionName` |
| معرّف التطبيق | `app/build.gradle` ← `applicationId` |

## ملاحظات

- مكتبة three.js بتتنزل وقت البناء وبتتحط جوه التطبيق، فاللعب الفردي بيشتغل من غير إنترنت. لو التنزيل فشل بيرجع يحمّلها من الإنترنت.
- زر الرجوع بيوقّف اللعبة (أو بيقفل لوحة الإعدادات/الأونلاين)، ولو ضغطته مرتين ورا بعض بيخرج. والتطبيق بيوقّف اللعبة لوحده لما تطلع منه.
- الـ APK ده موقّع بمفتاح debug، يعني مناسب للتثبيت المباشر على موبايلك. لو هترفعه على Google Play هتحتاج مفتاح توقيع خاص بيك.
- تعديل بسيط في `server/server.js`: بقى يدوّر على `asylum_game.html` جنب نفسه أو جوه فولدر `assets`، عشان يشتغل من جوه المشروع.
